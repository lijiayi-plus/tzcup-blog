记录一下VSCODE的配置

ssh-keygen -t ed25519 -C “claw@windows”

有两个文件id_ed25519 （私钥）
id_ed25519.pub （公钥），复制下来公钥

ssh claw@8.155.146.125登陆服务器，
mkdir -p ~/.ssh
apt update && apt install -y nano
nano ~/.ssh/authorized_keys写入公钥，
Ctrl+O → 回车 → Ctrl+X
然后chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys

ssh claw@8.155.146.125能免密登就完成一半了，然后vscode下载remote -ssh

编辑这个文件写C:\Users\你的用户名.ssh\config，里面写
Host newserver
HostName 8.155.146.125
User claw
IdentityFile C:\Users\你的用户名.ssh\id_ed25519

如下是我的电脑的实际配置：
Host autodl-3090-318
HostName connect.nmb2.seetacloud.com
User root
Port 43659
IdentityFile C:\Users\23526.ssh\id_ed25519
StrictHostKeyChecking no
要确保文件里面的缩进一致
